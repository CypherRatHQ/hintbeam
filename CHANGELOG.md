# hintbeam

Every release, newest first. Entries are written for the person upgrading: what changed, why it
matters, and the upgrade step when there is one. Versions follow [Semantic Versioning](https://semver.org)
as described in [docs/versioning.md](docs/versioning.md).

Changes waiting for the next release live in [`.changeset/`](.changeset); they are added here when
the release is cut.
